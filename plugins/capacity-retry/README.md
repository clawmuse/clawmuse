# 模型满载自动重试

在插件列表启用“模型满载自动重试”，进入插件设置调整最多重试次数和间隔秒数。
默认在原始失败后最多重试 3 次，每次等待 30 秒。设置作用于该主机上的会话。

插件识别 `Selected model is at capacity. Please try a different model.`，包括带
`[System Error]` 前缀的提示。只处理结构化回合错误或本轮最后一条错误、助手消息，
不匹配引用示例、鉴权错误或额度耗尽。每次重试在原会话发送“请继续完成上一条任务。”，
保留当前模型和上下文。它不保证原请求完全重放，已执行的工具也不会回滚。

重试进度、次数用尽和重试结束提醒保存在原会话中；没有手机后台推送。
非容量错误会结束重试并提示查看本轮结果。手动发送消息、取消回合、归档、关闭会话、
权限请求、修改设置或禁用插件会清除等待任务。发送前会检查会话是否空闲。
主机或插件重启后不恢复等待任务；启用前已经结束的失败回合不会自动重试。

开发时可安装目录源：

```bash
npm run cli -- plugin install /absolute/path/to/clawmuse/plugins/capacity-retry
```

插件随安装包提供，默认关闭。无需重启管理现有任务的主守护进程。

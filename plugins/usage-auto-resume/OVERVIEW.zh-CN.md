Usage Auto Resume 在 Codex、Claude 或 Antigravity Agent 因额度限制停止时，为同一个 Agent 安排继续提示。已知的重置时间有两分钟缓冲。Codex 和 Claude 需要在发送前重新检查账户和额度；Antigravity 直接按通知中的重置时间继续，不做账户或额度验证。

Auto Resume 侧边栏页面按天分组成员恢复计划，显示时间、状态、会话、提供方和工作区。可以关闭某条计划、延后十分钟、输入其他时间，或将已显示的计划一并关闭。验证等待会显示下次检查时间。

## 安装要求

需要 Paseo daemon 和 app 0.12.0 或更高版本、已启用插件、已有 CLI 登录和一个运行中的 daemon 主机。内置和派生提供方默认开启；按提供方的开关立即生效。关闭提供方会取消其待处理的恢复计划，重新打开不会恢复。

macOS 上的 Claude 会读取所选 profile 的 Keychain 或备用凭据文件。API key 和外部计费通道不在范围内。

## 数据与限制

插件读取 Agent 状态、最近的通知、提供方配置和 CLI 凭据。账户和额度请求使用 OAuth token，但不刷新它们；token 不会存入任务也不会写日志。恢复计划保存在本地。继续提示通过 Paseo 送达现有 Agent 的提供方。

新消息、进行中的回合、已关闭或已归档的 Agent，以及待批准的权限都会取消恢复。未验证的 Codex/Claude 登录或额度会进入等待。恢复计划跨重启保留；检查需要生命周期事件或 Auto Resume 请求来重新接入 API。子 Agent 的继续取决于父 Agent 的工具。

ClawMuse 增加了持久化文本队列：额度耗尽时可保存补充内容；现有的继续提示先完成，随后队列中的消息逐回合执行。可从输入框旁或 Auto Resume 页面管理队列。

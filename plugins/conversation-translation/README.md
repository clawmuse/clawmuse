# 会话翻译

这是 ClawMuse 随附的官方可选插件。打开 **设置 → 主机 → 插件 → 会话翻译**，开启插件后进入配置页，使用与聊天输入框相同的模型面板，选择这台主机聊天时可用的 Provider 和模型（包括 GROK、自定义 Provider）。工具和模型都不预选；保存完整配置后才开始翻译。以后可直接点击插件行的 **配置** 返回；可以先点击 **测试翻译** 验证登录和模型。

插件默认停用，遵循插件总开关；停用时卸载消息钩子和客户端扩展。已开启但尚未配置时保留原来的聊天流程，不调用任何模型。后续启停保留你保存的选择，每台主机独立配置。翻译模型与编程会话的模型独立，复用主机 Provider 的命令、环境、自定义模型配置、登录状态和额度。

输入在交给 Agent 前译成英文；失败会阻止发送，聊天保留可重试的草稿。Claude Code、Codex、OpenCode 等编程会话共用这个入口。新增到主机的 Provider 会自动出现在翻译模型面板，无需另加白名单。首条输入、后续消息和排队后发送的消息都经过翻译，斜杠命令、附件、内部辅助会话和带来源的 Agent 消息跳过。开启前的历史上下文不会被重写。

回复在本轮 Agent 结束后按完整消息翻译，生成期间显示原文。同一聊天同时就绪的消息合并请求，保留 Markdown 列表和引用，不拆分完整消息。点击 **英文原文** 查看原始回复。题目卡片的标签、问题、选项、说明、输入提示和自定义关闭文字，以及计划确认卡片的正文与说明，也会翻译。翻译期间或失败时仍可用原文继续操作，失败后可在卡片内重试。题目翻译不改变已选答案或手动输入，提交时使用原始字段名和选项值。译文只进入显示层，不写回 Agent；工具调用、工具结果和选项代码预览保留原样。旧客户端没有交互内容翻译入口时仍只翻译消息，需要更新客户端才能翻译题目与计划卡片。引用或附加历史仍使用规范原文。代码围栏、行内代码、识别出的路径、URL、JSON 和整行常见命令先替换为标记，验证后恢复。自然语言内的命令请用反引号包住。

每次翻译通过主机 Provider 适配器创建独立临时会话，不恢复编程会话、不创建工作区，也不进入主机聊天历史。翻译不经过消息钩子，不注入 ClawMuse 工具或 MCP；出现权限请求时终止任务。请求 Provider 不保存原生会话，但是否支持由 Provider 决定。各 CLI 自身的工具和配置行为仍由其适配器控制，临时目录不是系统沙箱。翻译使用所选模型，不自动切换到其他服务；失败时可在设置中重试或更换模型。

同一客户端串行处理翻译请求，当前题目和计划优先于等待中的历史回复；卸载的页面不再启动排队任务。Agent 运行时可提前准备隔离的模型会话，不生成额外内容。排队和进程准备共用 15 秒额度，正文翻译限时 8 秒；超时保留原文并提供手动重试。页面切换或重新连接不自动重试失败回复。题目字段合并为一次请求，每个字段独立保护字面量并校验顺序，失败结果不缓存。主机合并相同请求并缓存最近 256 个结果。更换翻译模型会使用新的缓存，旧配置的排队请求不会调用新模型。原始输入保存在 `$PASEO_HOME/conversation-translation/originals/`，权限为仅主机用户可读写，用于重新连接或重启后的双语显示；删除该目录会失去原始输入对照，不影响 Agent 的英文历史。回复缓存随守护进程退出清除。

本功能借鉴 [Fanyi](https://github.com/JrCx7scC/claude-code-fanyi) 的输入替换和仅显示译文、[cctrans](https://github.com/roy-jiang-opus/cctrans) 的缓存思路，以及 [PromptKit](https://paseo.sh/plugins/hungcuong9125/prompt-kit) 的独立 CLI 调用和字面量保护。实现使用 Paseo 自己的消息入口和跨平台插件界面，没有复制终端补丁代码。

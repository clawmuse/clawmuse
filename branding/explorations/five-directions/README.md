# ClawMuse · 五个品牌方向

本目录只包含独立提案，不修改官网或应用。

- 01 精密构造：块面 CM + 紧凑重字标，适合专业工具型 SaaS。
- 02 衬线编辑：交织 CM + 衬线与斜体，让 Muse 的创作属性更突出。
- 03 斜切动感：斜切的带状 CM 与前倾字标，把“行动”做成视觉重心。
- 04 圆润亲和：柔软的 CM 与饱满圆字，让日常使用更有亲近感。
- 05 像素终端：网格像素字与 CM 模块，保留终端工具的鲜明个性。

打开 index.html 可单独查看方案、切换深浅背景及图标/品牌字模式。comparison.png 是总览，comparison.svg 可无损放大。

每个方案目录含图标、品牌字、横向组合、对应浅色版、应用图标和大图预览。标识 SVG 的字母均为路径，不需要安装字体；可在 Figma、Illustrator 等工具中继续修改。

排印基础：01 Arial Black；02 Georgia / Georgia Italic；03 Arial Black 倾斜处理；04 Arial Rounded Bold；05 自绘像素字。图标为此次提案绘制；字体文件不包含在素材包中。选定方向后再定制字距、局部字形和实际应用尺寸。

生成脚本使用当前工作区的 opentype.js 与 sharp，并读取 macOS 字体，只用于此提案。导出的 SVG 不依赖这些工具。
